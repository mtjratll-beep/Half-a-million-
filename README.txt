نظام خدمة السيارات - النسخة المرتبة للعامل

التعديلات:
- حذف دليل الخدمات بالرسومات من صفحة العامل.
- حذف مربع تحديث حالة العمليات من واجهة العامل.
- ترتيب واجهة الجوال بشكل مختصر ومريح.
- إضافة زر إعدادات بأيقونة SVG أصلية (بدون إيموجي) في رأس الصفحة.
- نقل الحالة واللغة والنغمة والجرس وخروج إلى قائمة الإعدادات.
- تحسين أحجام الأزرار والمسافات وشريط الطلبات السفلي للجوال.

- إضافة تجهيز إشعارات Push للعامل/الكابتن عبر Firebase Cloud Messaging عند إغلاق الموقع.
- إضافة firebase-messaging-sw.js للإشعارات في الخلفية.
- المدير لا يتم تسجيله في إشعارات العامل ولا توجد له نغمة أو رنين.
- لإكمال التشغيل الفعلي خارج الموقع يجب وضع Web Push certificate public key (VAPID) من Firebase Console مكان القيمة المحددة في index.html، ثم إعداد إرسال FCM عند إنشاء الطلب.
